### Sub-task B: Parallel pool with p-limit

**Status:** [ ] pending

**Intent**
Replace the sequential `for` loop in `certify()` with a bounded parallel pool. Each of the `concurrency` slots runs one candidate at a time; its slot index (0-based) is passed as `workerIndex` to `certifyOne` and forwarded in every `ForgeEvent`. This is the "parallel evidence" screenshot moment for the judging criteria.

**Expected Outcomes**
- `certify()` honours the `concurrency` parameter (no longer ignores it).
- `void concurrency` stub is removed.
- All candidates run concurrently up to the pool limit.
- Each worker's `ForgeEvent` carries the correct slot index (0 = first slot, 1 = second, etc.).
- The returned `Certification[]` preserves original candidate order (or is returned as an unordered array of results - order is acceptable either way because T2.3 writes the funnel, not an ordered list).
- `npm run lint`, `npm run typecheck` still pass after the addition.

**Todo List**
1. Add `p-limit` to `packages/engine/package.json` dependencies.
2. Import `pLimit` from `"p-limit"` at the top of `certifier.ts`.
3. In `certify()`:
   - Remove `void concurrency` and the sequential `for` loop.
   - Create a `limit = pLimit(concurrency)` instance.
   - Map `candidates` to `limit(() => certifyOne(candidate, repoDir, emitter, slotIndex))` where `slotIndex` cycles `0..concurrency-1` by candidate position, or use the p-limit slot tracking pattern.
   - Use `Promise.all(...)` to collect results.
4. Verify slot assignment: the simplest correct approach is `slotIndex = i % concurrency` (candidate index modulo concurrency), since p-limit does not expose a slot concept natively.

**Relevant Context**
- File: [`packages/engine/src/certifier.ts`](packages/engine/src/certifier.ts) - lines 229-242 (the `certify` function).
- `p-limit` is an ESM-only package; the engine already uses `"type": "module"` in [`packages/engine/package.json`](packages/engine/package.json), so no CJS shimming is needed.
- `ForgeEvent` uses `worker: number` field (defined in [`packages/engine/src/types.ts`](packages/engine/src/types.ts) lines 97-101).
- `concurrency` already exists as a parameter with default `4`.
