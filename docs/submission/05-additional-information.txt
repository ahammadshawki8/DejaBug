TRY IT IN 2 MINUTES
Showcase (no install): https://ahammadshawki8.github.io/DejaBug/
Open a case, take it, press Run the tests, then Replay the original fix and run again. In the showcase, runs replay real recorded results and are labelled as replays; only a local install runs tests live. Difficulty 3 cases unlock at the Detective rank (300 XP), one or two solves in.

RUN IT LOCALLY
git clone https://github.com/ahammadshawki8/DejaBug
cd DejaBug && npm install && npm run dev
Then open http://localhost:5173. Needs Node 24+ and git; playing a case needs Go or Python with pytest. To forge cases from a new repository, add a watsonx.ai key (or a Bob API key) to .env; the 56 bundled cases work without any key.
