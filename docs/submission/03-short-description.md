# Short description
DejaBug turns a repository's real bug fixes into certified onboarding cases: each test is proven to fail before the fix and pass after it, and new hires solve them in a detective game, coached by a read-only IBM Bob mentor that cannot write the fix.

# Project title
DejaBug: your team's past bugs, replayed as training cases
