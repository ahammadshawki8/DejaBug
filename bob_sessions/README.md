# Bob task session summaries

Required submission evidence: PNG screenshots of **every** Bob IDE task session summary related to this project, from **every** team member.

How to capture one: Bob chat → **Tasks** → open the task (choose **All** if you used several workspaces) → click the **task header** → screenshot the consumption summary.

File name format: `<team>_task<NN>_<short_description>_summary.png`
e.g. `teamalpha_task01_login_flow_summary.png`

Take the screenshot as soon as each task finishes.
